# EP01 — บันทึกการผลิต

ทำตาม `TREATMENT.md` ของผู้เขียน พร้อมข้อตกลงที่ยืนยันก่อนสร้าง:

1. ความยาวรวม **56.5 วินาที** = 55 วินาทีตามบท + ภาพดำเงียบ 1.5 วินาทีตอนจบ (ภาพดำเป็นความตั้งใจ)
2. ผู้บรรยาย "เรา" = **มาลี** (ใช้ทั้งซีรีส์)
3. เกียรติถือ **มือถือ** (เพิ่มเข้า Continuity Lock ของเกียรติ) ยกขึ้นตอน "ถ้าเจอ ผมจะถ่ายรูปให้ดู"
4. ป้ายปากป่าเขียนว่า **"ห้ามเข้า"** สีแดงซีด
5. ไม่มีเสียงหัวเราะ (เสียงคนสังเคราะห์ไม่สมจริง) เกียรติไหล่สั่นแทน
6. ตัวละครเป็นภาพสีน้ำ ไม่มีใบหน้า ท่าทางเรียบง่าย
7. ซับ #4–#6 ขยับ: 0:19.0–22.4 / 22.4–25.4 / 25.4–29.0 (ผ่านเครื่องตรวจเวลาอ่าน `readcheck` ทุกบรรทัด)
8. ฉากศาลเริ่ม 0:18.5

## การจัดฉาก (ใช้ซ้ำในตอนต่อไป)

| ฉาก | เวลา | ภาพ / กล้อง |
|---|---|---|
| เหนือป่า | 0–6 | ทะเลยอดไม้ในหมอก เครื่องบินใบพัดสีเทาบินซ้ายไปขวาเข้าหมอก กล้องแพนตาม → หมอกเต็มจอเปลี่ยนฉาก |
| ปากป่า | 6–44.5 | ฉากเดียว เคลื่อนกล้องต่อเนื่อง: กลุ่ม 4 คนหันหลัง พรานชัยหันหน้าที่ปากป่า (ป้าย "ห้ามเข้า" ซ้าย ศาลผ้าแดงขวา) → ดันกล้องเข้าพราน (ยกมือ) → แพนไปศาล (ชี้ทาง ผ้าสะบัด) → ตามเกียรติ (ไหล่สั่น จับหมวก ยกมือถือ เดินเข้าป่าก่อน) → ทุกคนเดินเข้าไป แสงข้างนอกหายไป |
| ในป่า | 44.5–55 | หมอกเข้ม → กลุ่มหยุด (หันหลัง พรานนำหน้า) พรานยกมือ ทุกคนเงยหน้า ใบไม้สั่น กล้อง tilt up ช้าๆ ถึงช่องยอดไม้ ท้องฟ้าว่าง → เงียบ 1.6 วิ → เสียงต่ำ → ดำ |

## ซับบทพูด
บทพูดตัวละครใส่ในเครื่องหมายคำพูด มีจุดสีนำหน้า: ส้ม = พรานชัย, แดง = เกียรติ · บทบรรยาย (มาลี) เป็นซับปกติ

## เสียง
ลม ใบไม้ นก (เฉพาะนอกป่า) เสียงเดินบนใบไม้ทุกก้าว ผ้าศาลสะบัด ไม้ศาลลั่น ตะเกียง แผนที่ วิทยุ ·
เครื่องบินจริง 0–6 วิ (ซ้าย→ขวา) · เครื่องบินผี 45–52.6 วิ (หนักกว่า ก้อง เหนือหัว) → เงียบ 52.6–54.2 → เสียงต่ำ 54.2 → ดำ 55
ดนตรี: โดรนเสียงสีต่ำ คาลิมบาโน้ตเพี้ยน เสียงแก้วไต่ระดับ กรองช่วงเสียงกลางไว้ให้พากย์ทับได้
