# ป่าที่ไม่ยอมให้ใครกลับ (The Forest That Keeps You)

- **แนว:** สยองขวัญ / ลึกลับ / เอาชีวิตรอด
- **เรื่องย่อ:** ทีมค้นหา 4 คนกับพรานนำทางเข้าป่าดิบชื้นเพื่อตามหากล่องเหล็กจากเครื่องบินที่หายไป ป่าเริ่มเลียนเสียงคน เส้นทางวนกลับที่เดิม และสมาชิกหายไปทีละคน สุดท้ายผู้รอดต้องเลือกระหว่างกล่องกับชีวิต
- **ตัวละคร:** นิรันดร์ (แจ็กเก็ตเขียวเข้ม), เกียรติ (เสื้อแดงหม่น), มาลี (เสื้อเหลืองหม่น), ต้น (เสื้อฟ้าหม่น), พรานชัย (เสื้อคลุมน้ำตาล + ตะเกียงส้ม) — รายละเอียดใน [STORY_BIBLE.md](STORY_BIBLE.md)
- **จำนวนตอน:** 6 ตอน ตอนละประมาณ 55–58 วินาที
- **สัดส่วนภาพ:** 9:16 แนวตั้ง 1080×1920, 30 fps
- **สไตล์:** watercolor-mystery (ภาพสีน้ำวาดด้วยโค้ด ไม่มีหน้าคน)
- **เสียง:** ซับไทย + ดนตรี + เสียงบรรยากาศ ไม่มีเสียงพากย์ (มีไฟล์ไม่มีซับไว้พากย์ทับ) ผู้บรรยาย "เรา" = มาลี

## กฎของป่า (ใช้ทุกตอน)

1. ห้ามตอบเสียงเรียก
2. ห้ามเดินออกจากเส้นทาง
3. หากนับคนไม่ตรง ห้ามนับซ้ำ
