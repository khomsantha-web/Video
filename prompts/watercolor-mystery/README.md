# บันทึกสีน้ำยามวิกาล (Watercolor Mystery)

- **แนว:** เรื่องเล่าลึกลับ / หลอนเงียบ ภาพสีน้ำวาดด้วยโค้ด (สไตล์ Watercolor Brush จาก lemo-opuscar ปรับโทนเป็นกลางคืน สีหม่น หมอก)
- **เรื่องย่อ:** สมุดบันทึกของคนวาดภาพสีน้ำที่ออกไปวาดสถานที่ร้างตอนกลางคืน ทุกตอนเริ่มจากสิ่งแปลกเล็กๆ ในภาพ และจบด้วยสิ่งที่ออกมาจากภาพ
- **ตัวละครหลัก:** "ฉัน" คนวาดภาพ (ไม่เห็นหน้า เห็นแค่หน้ากระดาษ พู่กัน และเงา)
- **ความยาว:** ตอนละ 45–60 วินาที
- **สัดส่วนภาพ:** 9:16 แนวตั้ง 1080×1920, 30 fps
- **เสียง:** ไม่มีเสียงพากย์ ใช้ซับไทยเผาลงภาพ + ดนตรี + เสียงประกอบ (มีไฟล์ไม่มีซับไว้พากย์ทับ)

## กฎของซีรีส์ (ใช้ทุกตอน)

1. ไม่มีหน้าคนชัด เห็นได้แค่เงาดำทึบ รอยเท้า หรือสิ่งของ
2. แสงคือกระดาษที่ไม่ได้ระบาย มีสี accent สีเดียวต่อตอน (ep01 = อำพันตะเกียง)
3. ทุกตอนเปิดด้วยลายมือ "คืนที่ …" และจบด้วยหมอกลบภาพกลับเป็นกระดาษเปล่า
