# ข้อความสำหรับวางใน ChatGPT — ตอน 2–8

```
ช่วยเขียนพรอมต์ภาษาอังกฤษสำหรับซีรีส์สยองขวัญสั้น ตอนที่ 2 ถึง 8 ให้หน่อย ใช้รูปแบบเดียวกับตอน 1 ที่คุณเขียนไว้แล้ว (ได้ผลดีที่สุด)

แต่ละตอนต้องมี 2 ชิ้น:
ชิ้นที่ 1: พรอมต์ภาพเฟรมแรก สำหรับสร้างใน Gemini (แนบรูปตัวละครไปด้วยทุกครั้ง)
ชิ้นที่ 2: พรอมต์วิดีโอ สำหรับ Google Flow (Veo) โหมด Frames to Video ยาว 8 วินาที

== เรื่อง ==
ซีรีส์ "ป่าไม่มีทางออก" เพื่อน 3 คนไปตั้งแคมป์ในป่าดิบเขาภาคเหนือของไทย ตื่นมาทางกลับหายไป ยิ่งเดินยิ่งวนที่เดิม และมีบางอย่างตามมาตั้งแต่คืนแรก
แนว cinematic horror ภาพแนวตั้ง 9:16 คลิปละ 8 วินาที บทพูดภาษาไทย

== ตัวละคร (แต่งตัวแบบนี้ทุกตอน) ==
- Nat ชาย 24 ผอม ผมดำสั้นยุ่ง เสื้อเชิ้ตลายสก็อตแดงดำเปิดทับเสื้อยืดดำ กางเกงคาร์โก้เขียวขี้ม้า รองเท้าเดินป่าน้ำตาล เป้สีเทา ไฟฉายคาดหัว
- Prang หญิง 23 ตัวเล็ก ผมดำมัดหางม้าต่ำ เสื้อกันฝนสีเหลืองมัสตาร์ด เลกกิ้งดำ รองเท้าเดินป่าน้ำตาล ถือไฟฉายเล็กสีเงิน
- Ton ชาย 26 ล่ำ ผมเกรียนสั้นมาก แว่นกรอบกลมสีดำ (ต้องใส่ตลอด) แจ็กเก็ตฟลีซสีกรมท่า (ไม่ใช่ฮู้ด) กางเกงคาร์โก้สีเทา รองเท้าเดินป่าดำ แบกถุงเต็นท์สีส้ม (เต็นท์เก็บอยู่ในถุงตั้งแต่ตอน 2)

== กฎของสิ่งลึกลับ ==
1. ห้ามเห็นชัด ได้แค่เงาสูง ผอมผิดสัดส่วน เบลออยู่ไกล ๆ
2. เมื่อมันอยู่ใกล้ เสียงป่าทั้งหมดเงียบกริบทันที
3. มันเลียนแบบสิ่งที่พวกเขาทำ (ผูกริบบิ้น เลียนเสียงคน กางเต็นท์)

== บทเรียนจาก 5 ครั้งที่ลองตอน 1 (ต้องกันไว้ทุกตอน) ==
- Veo ใส่ซับไตเติลภาษาอังกฤษสะกดผิดมาเอง → ห้ามซับ/ตัวหนังสือทุกชนิด
- Veo ตัดภาพไปโคลสอัปเองราววินาทีที่ 5.8 → ถ้าตัด ต้องให้ตัวละครหน้าเหมือนเดิม
- โคลสอัปแล้วแว่นของ Ton หาย → สั่งให้ Ton ใส่แว่นตลอด รวมถึงโคลสอัป
- คนพูดสลับตัว (Nat พูดแทน Ton) → ระบุคนพูดให้ชัด
- ฉากกลางคืนสว่างเกิน → ภาพเฟรมแรกต้องมืดจริง ระบุแหล่งแสงเดียวของฉาก นอกนั้นดำสนิท
- ไฟฉาย/ไฟคาดหัวที่เปิดอยู่ทำให้ฉากสว่าง → สั่งปิด ถ้าฉากไม่ได้ใช้
- พรอมต์วิดีโอยาว ๆ Veo ทำแค่จังหวะแรก → ไม่เกิน 120 คำ แบ่งเป็นช่วงเวลา 0–2s, 2–4s…
- ไฟฉายเล็กในป่าเล็กจนมองไม่เห็น → สิ่งสำคัญในฉากต้องเห็นชัดในเฟรม
- ให้ใช้บทพูดภาษาไทยตามที่ให้ไว้ทุกตัวอักษร พูดภาษาไทยเท่านั้น ไม่มีเพลงประกอบ

== ตอน 2: ทางหาย ==
เวลา/แสง: เช้าตรู่ หมอกเทา แสงสลัว
เหตุการณ์: เก็บเต็นท์แล้ว (Ton แบกถุงเต็นท์) Nat แหวกพุ่มเฟิร์นตรงที่เมื่อวานเป็นทางเดินเข้ามา แต่ข้างหลังมีแต่ป่าทึบ ไม่มีทาง Nat หันมาหาเพื่อนอย่างงง ๆ Prang กับ Ton มองหน้ากันอย่างกังวล
คนพูด: Nat พูดเบา ๆ งง ๆ — "ทางที่เราเดินเข้ามา... มันหายไปไหน"

== ตอน 3: ริบบิ้นแดง ==
เวลา/แสง: กลางวันใต้ร่มไม้หนา แสงเขียวสลัว เงาเข้ม
เหตุการณ์: Prang ผูกริบบิ้นสีแดงสดเส้นเดียวรอบลำต้นไม้ ข้างหลังเธอ เข็มทิศในมือถือของ Nat หมุนไม่หยุด Ton มองไปรอบ ๆ อย่างหวาดระแวง
คนพูด: Prang มุ่งมั่นแต่กังวล — "ผูกไว้ทุกต้นนะ เราจะได้รู้ว่าเดินผ่านมาแล้ว"

== ตอน 4: วนกลับมา ==
เวลา/แสง: บ่ายแก่ หมอกสีทองจาง ๆ เงายาว
เหตุการณ์: ทั้ง 3 คนหยุดเดิน รอบตัวมีริบบิ้นแดงแบบเดียวกันผูกอยู่ทุกต้นไม้ เป็นสิบ ๆ เส้น มากกว่าที่พวกเขาผูกไว้มาก ริบบิ้นไหวช้า ๆ ทั้งที่ไม่มีลม
คนพูด: Ton เสียงสั่น — "เราผูกไว้ทีละเส้นเองนะ... ใครผูกพวกนี้"

== ตอน 5: ป่าเงียบ ==
เวลา/แสง: พลบค่ำสีน้ำเงินมืด หมอกหนา แสงเหลือน้อยมาก
เหตุการณ์: เสียงแมลงและนกทั้งหมดหยุดพร้อมกันหลังวินาทีแรก Prang แข็งค้าง โคลสอัปหน้า Prang ไกลออกไปข้างหลังเธอ ระหว่างต้นไม้ในหมอก มีเงาสูงผอมมืดยืนนิ่ง เบลอ เห็นแค่ลาง ๆ (ครั้งแรกที่เห็นสิ่งลึกลับ) Nat กับ Ton เบลออยู่ข้างเธอ
คนพูด: Prang กระซิบเสียงสั่น — "ทำไม... เงียบไปหมดเลย"

== ตอน 6: เสียงเรียก ==
เวลา/แสง: กลางคืนมืดสนิท มีแค่ไฟคาดหัวของ Nat กับไฟฉายของ Prang
เหตุการณ์: Nat กับ Prang ยืนมองความมืด มีเสียงเหมือน Ton (แต่เพี้ยนนิด ๆ ก้อง ๆ) เรียกมาจากในป่า Nat ก้าวไปทางเสียง Prang คว้าแขนดึงไว้ กล้องแพนไปเจอ Ton ยืนอยู่ข้างหลังพวกเขา หน้าซีด กลัวมาก
คนพูด: เสียงจากในป่า — "นัท... มาทางนี้" แล้ว Ton กระซิบ — "นั่น... ไม่ใช่เสียงเรา"
หมายเหตุ: ภาพเฟรมแรกให้ Ton อยู่ในเงามืดด้านหลังตั้งแต่แรก หน้าจะได้ไม่เปลี่ยนตอนกล้องหันไปเจอ

== ตอน 7: รูปจากคืนแรก ==
เวลา/แสง: กลางคืนมืดสนิท แสงเดียวคือแสงสีฟ้าจากจอมือถือ
เหตุการณ์: ทั้ง 3 คนหลบอยู่หลังขอนไม้ล้มมีมอส Prang เปิดรูปที่ถ่ายรอบกองไฟคืนแรก แล้วซูมเข้า ในรูป ข้างหลังพวกเขาที่ขอบแสงไฟ มีร่างสูงผอมมืดยืนอยู่ หน้า Prang ซีด
คนพูด: Prang กระซิบตัวสั่น — "มันอยู่กับเรา... ตั้งแต่คืนแรก"
หมายเหตุ: รูปในจอต้องเหมือนฉากกองไฟตอน 1 (จะแนบภาพแคปจากตอน 1 ไปให้ Gemini)

== ตอน 8: ถุงนอนใบที่สี่ (ตอนจบ) ==
เวลา/แสง: กลางคืนมืดสนิท แสงเดียวคือกองไฟ
เหตุการณ์: ทั้ง 3 คนหยุดที่ขอบลานโล่ง หอบเหนื่อย ตรงหน้าคือแคมป์เดิมคืนแรก กองไฟยังลุก เต็นท์สีส้มกางอยู่ ทั้งที่ Ton ยังแบกถุงเต็นท์อยู่ ข้างกองไฟมีถุงนอน 4 ใบเรียงกัน ใบที่สี่รูดซิปเปิดเหมือนเพิ่งมีคนลุกออกไป วินาทีสุดท้ายกองไฟดับวูบ มืดสนิท
คนพูด: Nat กระซิบหอบ — "ถุงนอนใบที่สี่... ของใคร"
หมายเหตุ: แคมป์ต้องเหมือนตอน 1 (จะแนบภาพแคปจากตอน 1 ไปให้ Gemini)

ตอบเรียงตอน 2 ถึง 8 ทีละตอน แต่ละตอนมีชิ้นที่ 1 และชิ้นที่ 2 ในกล่องแยกกัน เพื่อให้คัดลอกง่าย
```
