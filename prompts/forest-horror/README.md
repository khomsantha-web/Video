# ป่าไม่มีทางออก (Forest Horror)

- **แนว:** สยองขวัญ / ลึกลับ แบบภาพยนตร์ (cinematic)
- **เรื่องย่อ:** เพื่อนสามคนไปตั้งแคมป์ในป่าดิบเขาภาคเหนือ ตื่นเช้ามาทางเดินกลับหายไป ยิ่งเดินยิ่งวนอยู่ที่เดิม และมีบางอย่างตามพวกเขามาตั้งแต่คืนแรก
- **ตัวละครหลัก:** [นัท](../../characters/nat.md), [ปราง](../../characters/prang.md), [ต้น](../../characters/ton.md)
- **จำนวนตอน:** 8 ตอน ตอนละ 8 วินาที
- **สัดส่วนภาพ:** 9:16 (แนวตั้ง)
- **บทพูด:** ภาษาไทย

## กฎของสิ่งลึกลับ (ใช้ทุกตอน ห้ามเปลี่ยน)

1. ห้ามเห็นชัด เห็นได้แค่เงาสูง ผอม ผิดสัดส่วน และเบลออยู่ไกล ๆ เท่านั้น
2. เมื่อมันอยู่ใกล้ เสียงป่าทั้งหมดจะเงียบกริบทันที
3. มันเลียนแบบสิ่งที่พวกเขาทำ เช่น ผูกริบบิ้น เลียนเสียงคน กางเต็นท์

## วิธีทำใน Gemini + Flow (ทำตามลำดับ)

1. **สร้างภาพตัวละครก่อน:** คัดลอก "Prompt ภาพตัวละคร" จากไฟล์ตัวละครทั้ง 3 ไปสร้างใน Gemini เลือกภาพที่ชอบที่สุดของแต่ละคนแล้วบันทึกไว้
2. **ใส่ภาพอ้างอิงใน Flow:** อัปโหลดภาพตัวละครทั้ง 3 เป็นภาพอ้างอิง (Ingredients) หน้าตาจะได้เหมือนกันทุกตอน
3. **สร้างทีละตอน:** คัดลอกกล่อง Prompt ของแต่ละตอนไปวางใน Flow แล้วสร้างวิดีโอ
4. **จดผล:** ตอนไหนต้องแก้ ให้จดไว้ในหัวข้อ "หมายเหตุ" ของตอนนั้น หรือบอกผมให้ปรับ Prompt
5. **ต่อคลิป:** เรียงตอน 1–8 ต่อกันใน Flow หรือแอปตัดต่อ
